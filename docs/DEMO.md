# Roteiro de avaliação

Este roteiro permite conhecer o projeto em poucos minutos.

1. Inicie a aplicação conforme o README.
2. Entre com `demo@portfolio.local` / `Demo@12345`.
3. Observe o **Dashboard** para entender a visão consolidada.
4. Abra **Funcionários/RH** para ver regras e histórico de pessoas.
5. Entre na **Agenda** e observe relacionamentos entre equipe, obra e operação.
6. Acesse **Frota** para visualizar posições e custos simulados.
7. Consulte **Financeiro** para entender os vínculos entre operação e cobrança.
8. Abra o **Portal das equipes** com `pessoa.demo1` / `DemoPortal123`.

## O que observar tecnicamente

- autorização por perfil;
- persistência local real no modo demo;
- dados relacionados entre diferentes módulos;
- isolamento de integrações externas;
- tratamento de fluxo de campo e confirmação idempotente;
- testes e documentação de decisões técnicas.
