# v1.0.0-portfolio

Primeira release consolidada da edição de portfólio do Sistema de Gestão Operacional.

## Destaques

- Demonstração local com autenticação independente de serviços externos.
- Cenário sintético de pessoas, equipes, obras, agenda, frota e financeiro.
- Capturas reais de Agenda, Frota e Financeiro no README.
- Execução com `docker compose up --build`, persistência em volume e acesso restrito ao computador local.
- Contêiner sem root, configuração explícita de demonstração e integrações desligadas.
- CI com testes Python, JavaScript, build Docker e teste HTTP de login e dados.
- Revisão de referências pessoais nos arquivos e no histórico antes da publicação.

## Avaliar

```bash
docker compose up --build
```

Abra http://127.0.0.1:8000 e entre com `demo@portfolio.local` / `Demo@12345`.

## Limites

Esta é uma edição de avaliação local com credenciais públicas. Não é uma implantação de produção nem um serviço multiusuário público. Emissão fiscal, cobranças e mensagens reais requerem uma instalação operacional própria. A revisão do código e do histórico não constitui garantia absoluta de segurança.
