# Segurança

Este repositório é uma versão sanitizada para portfólio. Não envie credenciais reais, arquivos `.env`, certificados, chaves privadas, bancos de produção ou documentos de pessoas/empresas.

O modo recomendado é `DEMO_MODE=true`. Integrações externas devem permanecer desabilitadas até que credenciais próprias de um ambiente de teste sejam configuradas localmente.
