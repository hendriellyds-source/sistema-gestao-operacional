# Segurança

Este repositório é uma versão demonstrativa e anonimizada de uma aplicação operacional.

## Princípios

- nenhum segredo de produção deve ser versionado;
- `.env` e bancos locais devem permanecer fora do Git;
- integrações externas ficam desabilitadas por padrão;
- credenciais do modo demo não possuem valor fora do ambiente local;
- dados de pessoas, clientes e empresas usados na demonstração devem ser fictícios.

## Relato de vulnerabilidades

Caso identifique uma vulnerabilidade, evite abrir uma issue pública contendo detalhes exploráveis. Entre em contato com a responsável pelo repositório por um canal profissional indicado no perfil do GitHub.
